# TrueVision tactical interface

Version 2.0 uses original tactical surfaces and a small event-driven navigation rail over native Steam UI. It loads no third-party theme CSS or JavaScript and no longer requires Minimal Dark.

Existing Raphael, Great Sage, Luminous and Veldora artwork generators remain unchanged. Title outlines use Noto Serif JP under the included SIL OFL. The scene reconstructions are unofficial fan artwork; see the profile reference notes.

Luminous / Asmodeus is an original life/death interpretation, with its own artwork generator, gothic texture and notification badge. Skill identity and life/death authority are corroborated by the official Tensura glossary; character appearance by the official character page. Its tracery is not claimed to be a canonical skill seal. See LUMINOUS-REFERENCES.md.
